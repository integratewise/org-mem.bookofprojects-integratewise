## 12. Flow Model

The continuous data loop follows an 8-stage lifecycle:
`Ingest → Normalize → Store → Render → Think → Govern / HITL → Act → Re-ingest`

1. **Ingest**: Connector pulls raw data from tools, files, or webhooks.
2. **Normalize**: Standardizes schema into Spine canonical models.
3. **Store**: Persists with vector embeddings and relational links.
4. **Render**: Projects onto relevant cockpit dashboards.
5. **Think**: AI evaluates trends, anomalies, and opportunities.
6. **Govern / HITL**: Checks policies and requests approval when necessary.
7. **Act**: Dispatches verified actions to target platforms.
8. **Re-ingest**: Records action receipts and updates organizational state.
